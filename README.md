# 🧁 Спечи кексик для Коннора

Інтерактивна гра в браузері: зайди в замок, спечи кексики для похмурого метрдотеля Коннора О’Дойла — і сподівайся, що він не перетвориться на вовка. 🐺

## Як грати
1. Натисни на замок, потім на кухню.
2. Клади в миску інгредієнти (борошно, цукор, яйця, масло — обов’язково; жучків і хробаків краще не треба) та змішай.
3. Постав у духовку й дістань у зеленій зоні шкали.
4. Виставити кекси на тацю й подивитися на реакцію Коннора.

## Запуск
Звичайний статичний сайт, без залежностей: відкрий `index.html` у браузері.

### GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root. Гра буде за адресою `https://<user>.github.io/<repo>/`.

## Структура
- `index.html` — уся гра (HTML + CSS + JS)
- `images/` — зображення замку, кухні, задоволеного Коннора та вовка

## Звуки
Усі звуки (бульк інгредієнтів, змішування, дзвінок духовки, фанфари, гарчання) синтезуються в коді через Web Audio API, окремих аудіофайлів немає. Звук вмикається після першого кліку (вимога браузерів). Кнопка 🔊 у куті вимикає звук.
